# Resources · Reference Shelf

Use official documentation as source of truth for syntax, versions, schemas and security guidance. Links can change; record version/date where a procedure depends on them.

## Official references

- [MITRE ATT&CK](https://attack.mitre.org/) — tactics and techniques.
- [Sigma](https://sigmahq.io/) — shareable detection rule format.
- [Splunk Search Reference](https://docs.splunk.com/Documentation/Splunk/latest/SearchReference/WhatsInThisManual) — SPL syntax.
- [Wazuh Documentation](https://documentation.wazuh.com/) — agents, rules and integrations.
- [Microsoft Learn: Windows audit logon events](https://learn.microsoft.com/en-us/windows/security/threat-protection/auditing/basic-audit-logon-events).
- [Sysmon documentation](https://learn.microsoft.com/en-us/sysinternals/downloads/sysmon).
- [NIST SP 800-61 Rev. 2](https://csrc.nist.gov/pubs/sp/800/61/r2/final) — incident handling guidance; verify current publications before formal policy use.

## Mini glossary

| Term | Plain-language meaning |
|---|---|
| Alert fatigue | Reduced attention from excessive low-value alerts |
| Baseline | Documented view of ordinary activity in an environment |
| EDR | Endpoint detection and response tooling |
| IOC | Observable indicator such as a hash, domain or IP |
| SIEM | Platform for collecting, searching and analyzing telemetry |
| SOAR | Security workflow/orchestration tooling |
| TTP | Tactics, techniques and procedures describing behavior |
| Telemetry gap | Missing or unreliable data needed for a conclusion |
| False negative | Relevant behavior a detection fails to identify |
| Chain of custody | Documentation of evidence possession and handling |

## How to add a reference

Record title, publisher/owner, version/date, access date when useful, and the claim/process it supports. Prefer primary documentation over unattributed screenshots.
